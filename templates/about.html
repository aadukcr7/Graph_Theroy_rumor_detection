About the Project

A transparent approach to rumor detection

This project examines how rumors and organic information cascades spread through time by modeling them as temporal directed trees. Instead of relying on opaque neural representations, it uses interpretable graph-theoretic and temporal features so each prediction can be explained directly from the structure of the propagation process.

Project approach

Graph construction

Rumor-like cascades are generated as compact, hub-heavy trees, while organic cascades are modeled as longer and sparser chains. In both cases, each edge represents a single repost event in a temporal directed graph.

Temporal modeling

Each edge stores a delay, a timestamp, and a temporal weight. Faster reposts receive larger weights, while slower reposts receive smaller weights, allowing propagation speed to influence the classification features.

Prediction model

A RandomForestClassifier learns nonlinear decision boundaries from the extracted feature vector and predicts whether a cascade is rumor-like or organic, with confidence returned from class probabilities.

Temporal weighting feature

Weight equation

w(i,j) = 1 / ln(1 + delta_t)

Here, delta_t is the repost delay on edge (i,j). When delta_t is small, the denominator is small and the weight becomes large. When delta_t is large, the denominator increases and the weight decreases.

Why logarithmic scaling

A logarithmic transform compresses extreme delays so that very late reposts do not overwhelm the full feature space. This improves numerical stability while preserving meaningful differences between early and medium delays.

How it is used

The system computes the average temporal weight across all edges. Rumor-like cascades often contain many rapid reposts, so their average temporal weight tends to be higher than in slower organic cascades.

Edge-level implementation

  • For each directed edge (u,v), the generator samples a repost delay delta_t.
  • It stores timestamp(v) = timestamp(u) + delta_t.
  • It computes edge weight(u,v) = 1 / ln(1 + delta_t).
  • This weight is stored on the edge and sent to the frontend payload.
  • In the graph view, edge thickness is scaled according to this weight.
  • Hovering over an edge reveals the delay, stored weight, and formula evaluation for that connection.

Worked example

If one repost has delta_t = 2.00, then weight = 1 / ln(1 + 2.00) = 1 / ln(3.00) ≈ 0.910. If another edge has delta_t = 6.00, then weight = 1 / ln(7.00) ≈ 0.514. The faster edge therefore receives a larger temporal influence in both the visualization and the model features.

Code mapping

  • Weight computation is implemented in compute_edge_weight(delay).
  • Per-edge attributes such as delay, timestamp, and weight are attached when edges are created.
  • Average temporal weight and diffusion speed are derived from these values during feature extraction.

Mathematics used in this project

Graph structure metrics

  • Density: 2|E| / (|V|(|V|-1)) for an undirected view of the cascade.
  • Diameter: the maximum shortest-path distance between node pairs.
  • Radius: the minimum eccentricity across all nodes.
  • Center: nodes whose eccentricity equals the radius.
  • Average shortest path: the mean shortest-path length over all node pairs.

Centrality and shape

  • Degree centrality: deg(v) / (|V|-1).
  • Betweenness centrality: the fraction of shortest paths that pass through a node.
  • Closeness centrality: the inverse of a node's average distance to others.
  • Degree centralization: a Freeman-style score that measures how concentrated influence is around a small number of nodes.
  • Branching factor and leaf ratio quantify how widely the tree spreads and how concentrated the terminal nodes are.

Time-to-diffusion mathematics

  • Each edge stores both the delay delta_t and the cumulative timestamp t(parent) + delta_t.
  • Average temporal weight summarizes the urgency of repost behavior.
  • Diffusion speed is approximated as 1 / mean(delta_t), with a small epsilon for stability.
  • This combines topological and temporal signals in a single feature vector.
